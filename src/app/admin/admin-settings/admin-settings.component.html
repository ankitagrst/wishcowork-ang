Setup Guide

1 Local Development

  1. • Install XAMPP/WAMP and copy the api folder to your web root.
  2. • Run auto-setup.php to initialize the database.
  3. • Set API URL to http://localhost/wishcowork/api

2 Production Setup

  1. • Upload the api folder and configure database.php.
  2. • Set API URL to your production domain.
  3. • Ensure .htaccess is present for routing.
